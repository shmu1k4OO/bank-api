## 📋 Описание

Проект представляет собой объектно-ориентированную симуляцию банковской системы на Python. Реализована полная бизнес-логика работы с банковскими картами: выпуск, пополнение, переводы, оплата покупок, начисление кешбэка и процентов на остаток.

### Возможности

- ✅ Выпуск трёх типов карт:
  - **SimpleDebitCard** — базовая дебетовая карта
  - **CashbackDebitCard** — дебетовая карта с кешбэком (до 10%)
  - **SavingCard** — накопительная карта с ежемесячным начислением процентов
- ✅ Пополнение счёта (депозит)
- ✅ Переводы между картами
- ✅ Оплата покупок с проверкой MCC-кодов
- ✅ Запрет операций по определённым MCC (азартные игры)
- ✅ Лимитные проверки (депозит, перевод, оплата)
- ✅ История транзакций по карте и по банку
- ✅ Генерация PAN номера по алгоритму Луна
- ✅ Валидация ПИН-кода, ФИО, номера телефона
- ✅ Обработка ошибок с иерархией исключений
